# أرقام المرضي: ماسنجر ← جروب واتساب

## التشغيل
1. `cp .env.example .env` وعبّي القيم.
2. `npm install` ثم `npm start`.
3. افتح `http://localhost:3000` (اليوزر والباسورد من .env).

## الإعدادات من الداشبورد (تبويب "الإعدادات")
- **واتساب:** اضغط "اربط واتساب"، وامسح الـ QR، واضغط "حمّل الجروبات"، اختار الجروب واحفظه، وجرّب "ابعت رسالة تجربة".
- **الصفحات:** الصق User Token من Graph API Explorer (صلاحيات pages_show_list وpages_messaging وpages_manage_metadata)، علّم على الصفحات المطلوبة. السيرفر بيشترك في Webhook كل صفحة لوحده.
- الأرقام بتتاخد من الصفحات المفعّلة بس.

## الربط مع ميتا (مرة واحدة)
- App فيه منتج Messenger ← Webhooks ← Callback URL = `https://دومينك/webhook` و Verify Token = نفس VERIFY_TOKEN.
- لو حطيت APP_ID و APP_SECRET، السيرفر بيحوّل التوكن لتوكن طويل عشان توكنات الصفحات ما تنتهيش.
- رسايل المرضي الحقيقيين محتاجة App في وضع Live وصلاحية pages_messaging بعد App Review.

## ملاحظات
- لازم HTTPS على النت (انظر DEPLOY.md).
- خلّي `DATA_DIR` على تخزين دائم، وإلا الأرقام والإعدادات بتتمسح مع إعادة التشغيل.
